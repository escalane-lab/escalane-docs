# Quick start

Requires Python **≥3.11**. From the repository root:

```bash
uv sync
uv run pytest -q                 # offline unit + integration
uv run escalane --help
```

## Demo output (live)

Live Ollama `d3:4b` decide on the seed PHP 502 incident (`--require-live`, gate A3 → HITL on label precision; dry-run only):

![escalane decide live Ollama d3:4b A3 terminal output](/escalane-docs/demo/demo-decide-live-terminal.png)

## Mock decide (offline)

```bash
uv run escalane decide \
  --backend mock \
  --state src/escalane/examples/incidents/php_502.json \
  --catalog datasets/sysops_decide/catalog.yaml \
  --gate-config A3
```

## Dry-run execute

```bash
uv run escalane run --dry-run \
  --backend mock \
  --state src/escalane/examples/incidents/php_502.json \
  --catalog datasets/sysops_decide/catalog.yaml \
  --gate-config A0
```

Dry-run renders argv from the catalog (e.g. `systemctl restart php8.2-fpm`) with `side_effect_called=false`.

## Homelab example

```bash
uv run escalane run --dry-run \
  --backend mock \
  --state src/escalane/examples/incidents/homelab_jellyfin_unhealthy.json \
  --catalog datasets/homelab_decide/catalog.yaml \
  --gate-config A0
```

Expect: `docker restart jellyfin`.

## Optional live System One (Ollama)

```bash
uv run escalane decide \
  --backend ollama \
  --model d3:4b \
  --require-live \
  --state src/escalane/examples/incidents/php_502.json \
  --catalog datasets/sysops_decide/catalog.yaml \
  --gate-config A3
```

Published demo used **`d3:4b`**; the code default / Phase-0 seed pin remains **`d3:2b`** when `--model` is omitted.

Env overrides: `ESCALANE_BACKEND`, `ESCALANE_BASE_URL`, `ESCALANE_MODEL` (legacy `SYSONE_*` still accepted as fallback).

`--require-live` fails closed if the live backend is unreachable (no silent mock fallback).

## Writes

Real host mutation requires **both** `--allow-writes` and `ALLOW_WRITE_OPERATIONS=true`. The research default refuses live remediations without an injected test hook — keep dry-run until you intend otherwise.
