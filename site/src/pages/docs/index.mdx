# Docs

**Escalane** is the product name for the **escalane** research harness. Category: Decide & Act for catalog-bound ops.

## Composition (branding)

| Shorthand | Meaning |
| --- | --- |
| **Agent = LLM + tools** | Model invents / proposes tool calls |
| **Escalane = Decide + Act** | Model chooses; harness runs templates |
| Expanded | **System One + catalog harness** |

Agents *propose*. Escalane *selects* among authored playbooks (plus `escalate`). Multi-turn = repeated Decide→Act on a rail, not free tool generation.

## Thesis

The model never invents commands. It answers typed decisions (`choice` / `noul` / `score`). Side effects come only from catalog templates after gates pass. Dry-run is the default.
